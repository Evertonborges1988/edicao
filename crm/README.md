# Agenda Bela (CRM para beleza e bem-estar)

Next.js 15 + Supabase. Etapas 1-2: login/cadastro e agenda.

## Rodando
1. Crie um projeto no Supabase e rode `supabase/migrations/0001_base.sql` no SQL Editor.
2. `cp .env.example .env.local` e preencha URL e anon key.
3. `npm install && npm run dev`

Para testar rápido, desligue "Confirm email" em Auth > Providers > Email.
